Synthetic, throwaway fixture for the install-guide spike (docs/adr/0007). It follows the Debian steps of `_install-self-hosted-debian.mdx` (with the shared Debian start and end partials) and the "add the extension" steps of `_add-timescaledb-to-a-database.mdx`, on a bare target, with the guide's commands verbatim. **One step is not in the guide:** step 2, `sudo apt update`. A stock Debian 13 cloud image has no apt package lists, so the guide's first step (`apt install gnupg postgresql-common …`) fails with `Unable to locate package` until something runs `apt update`; Ubuntu's image ships its lists. It is reported as a docs finding, and this step comes out when the guide is fixed. Never a real docs page, never merged upstream — see `CONTEXT.md`'s "the dev fixture."

<TestPlan>
target: self-hosted
machine: bare
os: debian
1. fork the service
2. run command: `sudo apt update`
3. run command: `sudo apt install gnupg postgresql-common apt-transport-https lsb-release wget`
4. answer `Continue? [Y/n]` with `Y`
5. run command: `sudo /usr/share/postgresql-common/pgdg/apt.postgresql.org.sh`
6. answer `Press Enter to continue, or Ctrl-C to abort.` with `<Enter>`
7. run command: `echo "deb https://packagecloud.io/timescale/timescaledb/debian/ $(lsb_release -c -s) main" | sudo tee /etc/apt/sources.list.d/timescaledb.list`
8. run command: `wget --quiet -O - https://packagecloud.io/timescale/timescaledb/gpgkey | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/timescaledb.gpg`
9. run command: `sudo apt update`
10. run command: `sudo apt install timescaledb-2-postgresql-18 postgresql-client-18`
11. answer `Continue? [Y/n]` with `Y`
12. run command: `sudo timescaledb-tune`
13. answer `Is this correct? [(y)es/(n)o]:` with `y`
14. answer `Is this okay? [(y)es/(n)o]:` with `y`
15. answer `Tune memory/parallelism/WAL and other settings? [(y)es/(n)o]:` with `y`
16. answer `Is this okay? [(y)es/(s)kip/(q)uit]:` with `y` each time
17. run command: `sudo systemctl restart postgresql`
18. run command: `sudo -u postgres psql`
19. answer `postgres=#` with `\password postgres`
20. answer `Enter new password for user "postgres":` with `<PASSWORD>`
21. answer `Enter it again:` with `<PASSWORD>`
22. answer `postgres=#` with `\q`
23. run command: `psql -d "postgres://postgres:<PASSWORD>@localhost:5432/postgres"`
24. answer `postgres=#` with `CREATE EXTENSION IF NOT EXISTS timescaledb;`
25. answer `postgres=#` with `\dx`
26. answer `postgres=#` with `\q`
27. expect rows: `SELECT 1 FROM pg_extension WHERE extname = 'timescaledb'`
</TestPlan>
