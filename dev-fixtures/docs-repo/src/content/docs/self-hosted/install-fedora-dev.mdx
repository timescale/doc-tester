Synthetic, throwaway fixture for the distro matrix (#88, docs/adr/0008). It follows the Fedora steps of `_install-self-hosted-fedora.mdx` (with the shared `_install-self-hosted-redhat-x-platform.mdx` partial) and the "add the extension" steps of `_add-timescaledb-to-a-database.mdx`, on a bare Fedora 44 target, with the guide's commands verbatim. The guide builds its pgdg URL from `rpm -E %{fedora}`, so it names no release; this is 44, the newest pgdg publishes a repo RPM for with 43. **One line is not the guide's:** in step 4's repo file, `sslcacert=` points at `/etc/pki/ca-trust/extracted/pem/tls-ca-bundle.pem`, where the guide has `/etc/pki/tls/certs/ca-bundle.crt`. Fedora's `ca-certificates` stopped shipping that symlink (the Fedora 43 change "Dropping of cert.pem file"), so on a stock Fedora 44 image `dnf` fails with `Curl error (77): Problem with the SSL CA cert` and `timescaledb-2-postgresql-18` is never found. It is reported as a docs finding, and this line goes back to the guide's when the guide is fixed. Never a real docs page, never merged upstream — see `CONTEXT.md`'s "the dev fixture."

<TestPlan>
target: self-hosted
machine: bare
os: fedora
1. fork the service
2. run command: `sudo yum install https://download.postgresql.org/pub/repos/yum/reporpms/F-$(rpm -E %{fedora})-x86_64/pgdg-fedora-repo-latest.noarch.rpm`
3. answer `Is this ok [y/N]:` with `y` each time
4. run command:
   `sudo tee /etc/yum.repos.d/timescale_timescaledb.repo <<EOL
   [timescale_timescaledb]
   name=timescale_timescaledb
   baseurl=https://packagecloud.io/timescale/timescaledb/el/9/\$basearch
   repo_gpgcheck=1
   gpgcheck=0
   enabled=1
   gpgkey=https://packagecloud.io/timescale/timescaledb/gpgkey
   sslverify=1
   sslcacert=/etc/pki/ca-trust/extracted/pem/tls-ca-bundle.pem
   metadata_expire=300
   EOL`
5. run command: `sudo yum update`
6. answer `Is this ok [y/N]:` with `y` each time
7. run command: `sudo yum install timescaledb-2-postgresql-18 postgresql18`
8. answer `Is this ok [y/N]:` with `y` each time
9. run command: `sudo /usr/pgsql-18/bin/postgresql-18-setup initdb`
10. run command: `sudo timescaledb-tune --pg-config=/usr/pgsql-18/bin/pg_config`
11. answer `Is this correct? [(y)es/(n)o]:` with `y`
12. answer `Is this okay? [(y)es/(n)o]:` with `y`
13. answer `Tune memory/parallelism/WAL and other settings? [(y)es/(n)o]:` with `y`
14. answer `Is this okay? [(y)es/(s)kip/(q)uit]:` with `y` each time
15. run command: `sudo systemctl enable postgresql-18`
16. run command: `sudo systemctl start postgresql-18`
17. run command: `sudo -u postgres psql`
18. answer `postgres=#` with `\password postgres`
19. answer `Enter new password for user "postgres":` with `<PASSWORD>`
20. answer `Enter it again:` with `<PASSWORD>`
21. answer `postgres=#` with `\q`
22. run command: `psql -d "postgres://postgres:<PASSWORD>@localhost:5432/postgres"`
23. answer `postgres=#` with `CREATE EXTENSION IF NOT EXISTS timescaledb;`
24. answer `postgres=#` with `\dx`
25. answer `postgres=#` with `\q`
26. expect rows: `SELECT 1 FROM pg_extension WHERE extname = 'timescaledb'`
