# Pull self-hosted EC2 work ahead of roadmap Phase 7

The roadmap sequences self-hosted/EC2 testing as Phase 7 of 9, behind media publishability, multi-page scope, the automation/trust layer, vision, video, and even the Tier-0 SQL-only fast path. The PRD calls self-hosted TimescaleDB pages ~52% of total doc coverage — the single biggest expansion available — so we're building the EC2 target now instead of waiting for Phase 7's turn.

We annotate the roadmap's existing Phase 7 entry with a dated note pointing at the tracking issue, rather than renumbering all nine phases: renumbering would invalidate any GitHub issue that references a phase by number, while annotating costs one line and leaves the sequencing tension visible for whoever reads roadmap.md next.
